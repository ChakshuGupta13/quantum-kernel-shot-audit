# Publication Snapshot

This is a recorded 48-record pilot with 32 training and 16 shared test records.
The consumed test set is locked; publication is not permission to tune or repeat
evaluation against those records.

Numerical code, frozen design, fitted preprocessing, angles, pair order, counts,
matrix arrays and per-record predictions are preserved from the original run.
The public export replaces the machine-local prepared-directory path with
`preparation-v1`. Receipts and dependent plan hashes are refreshed for that
metadata projection. The original workspace artifacts are not overwritten.

The publication manifest lists every exported file and its SHA-256. It is an
integrity inventory, not independent scientific validation or formal verification.
TLC/SANY was not run. Recomputed diagnostic metrics and prediction checks do not
change the single-partition, single-seed scope of the results.

Use a fresh separate working copy for a different experiment. Do not delete
completion receipts or output reservations to make this test set reusable.
Historical plans are snapshots; a plan created at a different filesystem location
must bind that location and current source bytes rather than reusing an old
launch approval.

The source dataset is publicly licensed CC BY 4.0. No raw patient identifiers or
private account credentials are included. This is not a clinical screening tool,
a general method ranking, a quantum-speedup result or a new theorem.
