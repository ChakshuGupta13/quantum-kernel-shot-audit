# Display Dependencies

These locally vendored files make the recorded demo work without network access. They do not run the quantum experiment or fit classifiers.

| Dependency | Version | License | Local file |
| --- | --- | --- | --- |
| Chart.js | 4.5.1 | MIT | chart.umd.js |
| Lucide | 0.468.0 | ISC, with retained Feather attribution | lucide.min.js |
| IBM Plex Sans via Fontsource | 5.2.6 | OFL-1.1 | plex-sans.woff2, plex-sans-semibold.woff2 |
| IBM Plex Mono via Fontsource | 5.2.6 | OFL-1.1 | plex-mono.woff2 |

Sources are the published distributions of [Chart.js](https://www.npmjs.com/package/chart.js/v/4.5.1), [Lucide](https://www.npmjs.com/package/lucide/v/0.468.0), [Plex Sans](https://www.npmjs.com/package/@fontsource/ibm-plex-sans/v/5.2.6) and [Plex Mono](https://www.npmjs.com/package/@fontsource/ibm-plex-mono/v/5.2.6). The accompanying license files preserve the upstream notices. Font files are unmodified Latin-subset WOFF2 files.

Dataset attribution is in the project README; display dependency licenses remain separate.
